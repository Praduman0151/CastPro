# CastPro v2.1.0 — Native Engine test build

This build includes the merged Native Engine 2.0 gaming encoder backend.

## Test targets
- CastPro Phone APK on OnePlus Nord 5.
- CastPro TV APK on TCL Google TV / Android TV.

## Test checklist
- Install both APKs.
- Confirm receiver discovery and connection.
- Confirm live picture and audio.
- Test portrait/landscape changes, reconnect, stop/restart, and sustained gameplay.
- Compare native gaming mode with the Kotlin compatibility path.
- Record device model, Android version, codec, resolution, frame rate, bitrate, and observed latency.

## Important
This is a debug test build. Native Engine performance and device compatibility are not certified until physical testing is complete.

Build request: compile both debug APKs from the merged Native Engine 2.0 mainline.
